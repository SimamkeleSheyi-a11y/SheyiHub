# SheyiHub Post-Login Polish V4 — Product Upgrade

This pass turns the V3 visual system into a deeper product layer.

## Added
- Realtime connection state + reconnect banner so WebSocket failures are visible instead of silent.
- Safer instant-meeting action with verification guard, loading, success and API error feedback.
- Workspace system UI with active-workspace switching and member management.
- Kanban-style workspace tasks with create/search/priority/due-date/move/delete actions.
- First-run onboarding that guides account → workspace → collaboration.
- Workspace/task quick links on the dashboard.
- Tasks/Workspaces integrated into desktop sidebar, mobile navigation, Create menus and command search.
- Responsive behavior kept throughout.

## Backend required
The workspace/task pages expect the optional V4 backend patch in the companion bundle. Existing chat/meetings/auth remain unchanged.
